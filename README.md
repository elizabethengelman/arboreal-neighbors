# Arboreal Neighbors
## View the project here: [https://arboreal-neighbors.onrender.com](https://arboreal-neighbors.onrender.com)

## Summary
Arboreal Neighbors is a proof-of-concept project that explores creating an interactive map for Lancaster, PA, that allows residents to learn about the city's tree life using data from the city's Open Records Office. Initially ambitious, the project began with the concept of a detailed, street-level experience but evolved into a broader map-based visualization due to complexity and time constraints. The project uses D3.js for data visualization, focusing on mapping trees, implementing user interactions, and enhancing the aesthetic presentation with species-based color variations. Future work aims to refine the map's functionality and user interactivity.
